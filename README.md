# GolfSwingAnalyzer

A macOS-first golf practice video review app. The initial goal is to import two iPhone recordings, synchronize the down-the-line and face-on views, and compare swings with a 2D body-joint overlay.

## Current status

The initial macOS SwiftUI app target has been created in `GolfSwingAnalyzer/`. It currently contains Xcode's starter screen; the video import and analysis workflow has not been implemented yet.

## Planned first milestones

1. Create and run a minimal macOS SwiftUI app in Xcode.
2. Import one video and play it back.
3. Import two videos and synchronize them with a visible light cue plus a manual offset control.
4. Mark swing clips and compare them side by side.
5. Add a 2D pose overlay to each clip.
